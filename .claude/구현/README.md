# 구현 문서

이 폴더는 AI Sherpa 프로젝트의 **구현 과정**에서 참조하는 문서들을 관리합니다.
CLAUDE.md(프로젝트 루트)가 AI 코딩 도구의 공통 규칙이라면, 이 폴더는 사람이 보면서 따라가는 실행 가이드입니다.

## 파일 목록

| 파일 | 설명 |
|------|------|
| `AI셰르파_구현_협업_가이드라인.docx` | 전체 협업 가이드 (브랜치 전략, 단계별 구현, 머지 규칙 등) |
| `구현_체크리스트.md` | Phase별 완료 체크리스트 (진행 상황 추적용) |
| `모듈별_구현_명세.md` | 각 모듈의 입출력, 핵심 로직, 주의사항 정리 |
| `API_계약서.md` | 프론트-백엔드 간 API 인터페이스 상세 (mock 데이터 포함) |
