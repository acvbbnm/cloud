# 슬라이드 5 — AI Sherpa 셰르파 컨셉 + 5계층 파이프라인

**화면**: 상단 셰르파 메타포 + 하단 5계층 가로 다이어그램

**상단 문구**:

> **셰르파 (Sherpa)** — 등반가가 정상에 도달하도록 곁에서 안내하는 동반자.
> 정상에 *오르는 건* 등반가 본인.

**3 원칙** (CLAUDE.md §5):
1. AI 는 **판단하지 않는다** — 검색·요약·제안만
2. **결정성 100%** — 정적 가중치, 환각 없음
3. **오프라인 동작** — 폐쇄망(SNF-01) 호환

**하단 5계층**:

```
Layer 0      Layer 1      Layer 2     Layer 3       Layer 4
사고 접수 →  로그 수집 →  분석     →  AI 셰르파  → 시각화·보고
🔦 컴파스   📦 적재함    🧭 ATT&CK   📖 4-KB      🗺 보드+보고서
```

**시간**: 0:50

**멘트**:
> "AI 가 결론을 *대신 내려주는* 도구는 이미 많습니다. SOAR, SIEM. 그런데 그 답이 맞는지는 결국 수사관이 검증해야 합니다.
>
> 셰르파는 정상에 *대신 오르지 않습니다*. 옆에서 길을 비춰주죠.
>
> 시스템은 5계층 파이프라인 — 각 계층이 하나의 등불입니다. 단계마다 어둠이 한 칸씩 걷힙니다."

# 슬라이드 6 — 차별점 ① 단서가 단서답고  +  ② 증거 기반 결정

**화면**: 좌측 컴파스/Evidence Tree, 우측 적재함 흐름

**좌측 메시지**:

> 시중 도구는 *ATT&CK 매핑된 결과* 를 단서라 부른다 — 이미 답이 나와있음.
> 우리는 **단서 = raw observable** (IP·user·time·activity).
> 사고유형은 누적된 단서에서 *자연 발현*.

**우측 흐름**:

```
[로그 분석] → [V-1 적재함] → [observable 칩 클릭] → [컴파스 확률 갱신]
              raw event 단위    수사관 *명시적 채택*
```

**학술 정합**:
- **Pearl 1988** — Bayesian belief propagation (모든 가설 동시 추적)
- **Shannon 1948** — Information Gain (다음 단서 추천)
- **Peirce 1903** — Abductive reasoning (단서 → 가설)
- **Jaynes 1968** — Uniform prior (사전 편향 없음)
- **ISO/IEC 27035-1:2023** — Assess & Decide (평가/결정 분리)

**시간**: 1:00

**멘트**:
> "두 가지 차별점을 묶어서 보여드립니다.
>
> 첫째, 단서는 *raw 신호* 입니다 — IP 하나, 사용자 이름 하나. 그것들이 쌓이면서 사고유형이 *발현* 합니다. 시스템이 결정하는 게 아니라요. Pearl 의 Bayesian Belief Propagation 입니다.
>
> 둘째, *다음 단서 후보* 는 시스템 제안일 뿐이고, **클릭으로 채택이 안 됩니다**. 의도된 동작입니다. 수사관이 실제 로그를 보고 *raw observable* 을 직접 채택해야 진행됩니다. ISO 27035 의 *Assess & Decide* 흐름 그대로입니다."

# 슬라이드 10 — 확장성 (Roadmap)

**화면**: 3축 인포그래픽 + 하단 *설계 근거 한 줄*

**3축 표**:

| 수평 확장 (CSP·도구) | 수직 확장 (사고유형·KB) | 워크플로우 확장 |
|---|---|---|
| **KT Cloud** 추가 (단기) | AI 모델 침해 시나리오 | 다중 수사관 협업 |
| **AWS/Azure** 외산 CSP | 컨테이너·K8s 보안 | 사후 분석 통계 (case → 패턴) |
| **SIEM/SOAR** 연동 | IoT/OT 환경 | **MITRE Engage** 능동 방어 단계 |
| 외부 위협 인텔 (TIP) | KB 6종 (ENISA·SANS DFIR) | 자체 LLM 도메인 파인튜닝 |

**하단 메시지**:

> 5계층 파이프라인 + 정적 가중치 설계 덕분에 — **각 계층 독립, 코드 변경 최소**.
> Layer 1 매핑 룰, `weights.json`, ChromaDB 청크만 추가하면 된다.

**시간**: 0:40

**멘트**:
