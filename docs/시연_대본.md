1. Step 3 진입 시 상단 **📋 1차 정찰** 카드 자동 노출 (cold-start, NIST SP 800-86 §4.1)

> **시연 멘트**: "정찰 단서는 weight 가 약해서(5~20) 한 사고유형으로 급격히
> 쏠리지 않습니다. 사고유형 무관 약한 신호로 시작 — Robust Bayes ε-contamination
> (Berger 1985) 으로 모든 가설에 최소 1% floor 보장."

> 시퀀스(MITRE ATT&CK Flow)입니다. 각 가설의 시계열로 '어느 단서 시점에 강했나'

#### ④ 다단계 공격 chain 추적 (MultiStageBoard) — advance-stage

3. → 확정 chain: **자격증명 탈취 → 권한 상승 → 데이터 유출** (3단계 복합)

> **시연 멘트**: "Mandiant M-Trends 2024 — 평균 침해는 5~7단계. 단일 단계에서
> 종결하면 후속 공격을 놓칩니다. 수사관이 단계마다 확정하면 chain 이 확장됩니다."

### 4-A-2. Q1 — 단서 카테고리 → 다음 단서 카테고리 (LEADS_TO)

```cypher
MATCH (a:ClueCategory)-[:PIVOT_TO]->(h:NextClueHint)-[:LEADS_TO]->(b:ClueCategory)
RETURN a.name AS from_category, h.priority AS priority, b.name AS to_category
ORDER BY from_category, priority
```

> **시연 멘트**: "단서 1개를 잡으면 다음에 어떤 단서를 찾아야 하는지 룰 그래프로 시각화. AWS Detective Profile Guidance 와 동일 패턴."

📸 **캡처 1**: 그래프 뷰 풀스크린.

### 4-A-3. Q3 — 8 사고유형별 boost 합계 (가설 신호 강도)

```cypher
MATCH (h:NextClueHint)-[r:BOOSTS]->(it:IncidentType)
RETURN it.name AS hypothesis,
       count(r) AS boost_count,
       sum(r.weight) AS total_weight
ORDER BY total_weight DESC
```

> **시연 멘트**: "Bayesian posterior 갱신의 직관 — 어느 가설이 단서 풀에서 신호를 가장 많이 받는지. e233c64 commit 이전엔 4 가설만 boost 됐고, 5/14 dev3 추가 4 사고유형 (RANSOM·MISCFG·PHISH·INSIDER) 보강 완료."

📸 **캡처 2**: Table 뷰 (8행 모두 표시).

### 4-A-4. Q4 — ATT&CK 기법 Top 5

```cypher
MATCH (c:Clue)-[r:MAPS_TO]->(t:Technique)
RETURN t.tid AS technique, count(c) AS clue_count
ORDER BY clue_count DESC
LIMIT 5
```

> **시연 멘트**: "T1078.004(26) · T1078(24) · T1090.003(15) · T1098(13) · T1486(12) — 클라우드 도메인의 핵심 기법. 단서 풀이 클라우드 ATT&CK Matrix 의 어디에 집중되는지 한 눈에."

## 7. 📊 시연 임팩트 메시지 (발표용)

### 핵심 가치 4가지

1. **🧭 단서 기반 동적 베이지안 추론** (Phase E~P, 최대 차별화) — 정적 결정 트리가
   아니라 단서를 모아 가능성을 좁히는 Bottom-up Abductive 방식. 경쟁 솔루션
   (CrowdStrike·Mandiant) 의 단순 alert dashboard 와 달리, 수사관이 단서를
   조합하며 어택 체인을 직접 재구성.
   - Uniform prior 1/8 (Jaynes Max Entropy) → 베이즈 갱신 → Robust Bayes ε-floor
   - 2-Zone 컴퍼스 (광범위 탐색 → 사고유형 chain 구체화)
   - 다단계 공격 chain (CRED → PRIV → DATA) — 단일 사고유형 확정 X
   - 단서 → V-5 Evidence Board 1st-class 노드 연동
2. **🤖 결정성 100% + AI 보조 분리** — 베이즈 추론·갭 감지·매핑·사후검증 모두 정적
   규칙/산술. LLM 은 KB 검색·요약·제안만, 판단 X (수사관이 단계마다 확정/거부).
3. **📚 외부 표준 인용** — KISA·MITRE ATT&CK Cloud v14·ATT&CK Flow·NIST 800-86/61r2·
   ISO 27037/27035·OCSF·CSA Top Threats 2024·Berger 1985 Robust Bayes·Mandiant M-Trends 2024
4. **🔁 V-1 ↔ V-8 양방향 검증** — 수사관 결정 → Layer 2 매핑 → 사후 검증 보완.
