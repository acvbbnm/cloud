## 7. dev / dev2 두 트랙 채택 결정 (마감 직전)

본 매핑은 **dev2 기준**. 학기 마감 시점에 dev vs dev2 채택 결정 필요 (청사진 § 9):

| 영역 | dev | dev2 |
|---|---|---|
| SF-00 가이드 | 단순 시드 5건 | 9 카테고리 × Kill Chain × 환경 보정 |
| 학술 변호력 | 약함 | **강함** (외부 표준 6종 명시 인용) |
| 시연 임팩트 | 보통 | **강함** (출처 칩 + 매트릭스 + 환경 보정 가시화) |
| 안정성 | 검증 충분 | E2E 검증 완료 |
| 코드 양 | 적음 | +1,600줄 (시드+백엔드+프론트) |

**현재 정책**: 두 트랙 병행 유지. V-1 Step3 에서 사용자가 토글로 비교 가능. 학기 마감 직전에 dev2 → dev 머지 결정.
