## 4. 시연 (브라우저 동작 확인)

### 4.1 evidence_tree 모드 (TRIAGE_MODE=evidence_tree 일 때)

1. **V-0 시작** → 새 케이스 생성 (CSP·심각도·시스템 구성)
2. **V-1 Step 1·2** → 사고유형 미확정 (UNCLASSIFIED) 로 진입
3. **V-1 Step 3** → 새 화면:
   - 첫 진입 시 **"🔦 어두운 맵을 단서로 밝혀가는 수사"** 안내 모달
   - 트리 화면 중앙에 **빈 트리 + 횃불 안내**
   - 좌측 **단서 직접 입력** 또는 **부분 로그 분석** 또는 ✛ **LogAnalysisFab** (플로팅)
4. **첫 단서 입력** → 트리에 단서 노드 등장 + 우측 IG 후보 풀 활성화
5. **우측 가설 카드 클릭** (랜섬웨어 53% 등) → inline 가이드 미리보기 expand
6. **[전체 가이드 보기 →]** 클릭 → 트리 위 풀 가이드 모달 (팝업)
7. **단서 3개 채택** → "사고유형 확정 가능" 알림 (depth ≥ 3 + 임계)
8. **[확정하고 다음 단계]** → V-2 진행

## 6. 트러블슈팅

| 증상 | 원인 | 해결 |
|---|---|---|
| **`/api/guide/preview` 404** | 백엔드가 K.1 commit (`35631d2`) 이전 | uvicorn 재시작 (Ctrl+C → 재실행) |
| **pgmpy ImportError** | requirements.txt 미반영 | `pip install -r requirements.txt` 재실행 |
| **`clue_dag.json` 없음 (BN 추론 시)** | H.4 학습 산출물 미생성 | `scripts/build_clue_attack_mapping.py` 실행 |
| **frontend axios CORS** | 백엔드 미실행 또는 다른 포트 | `.env` 의 `VITE_API_URL` 확인 (기본 `http://localhost:8000`) |
| **`netstat 8000 사용 중`** | 좀비 uvicorn | `taskkill /F /PID <PID>` 후 재실행 |
| **트리 안 자라남** | DB 에 옛 5-후보 트리 잔존 | 트리 화면 헤더 `⟲ 초기화` 버튼 클릭 → cold-start |
