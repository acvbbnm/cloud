## 6. 참고 — 본 감사가 잡지 않은 영역

- HTTP status code (`raise HTTPException(status_code=404, ...)`) — FastAPI 관용 표현, 정책 아님
- SQLAlchemy 컬럼 길이 (`VARCHAR(36)` 등) — 설계서 5.2절 명시값
- 한국어 docstring 안의 숫자 (단순 설명용)
- 주석 안의 magic — 코드 동작 미영향
