   - **추정 작업**: 1h (action_logs 테이블 SELECT + 직렬화 + 라우터 등록)

2. **`/api/report/export?format=pdf`** — 본 테스트는 docx만 검증. PDF 변환은 별도 (이전 갭 분석 보고서의 C3 항목과 동일)
3. **`POST /api/analysis/normalize` 응답 rate 0%** — 이전 케이스의 OCSF 데이터가 누적되어 normalize 시점에 새 raw 1건 처리 결과만 반영됨. 의도된 동작인지 / 누적 모드인지 검토 필요.

### P2 — 향후
4. **L3 chat 응답 시간 100초+** — 스트리밍 응답 적용 권장 (`stream=true`)
5. **/api/sherpa/brief response.technique_id=None** — RAG에서 KB 청크는 인용되나 technique 메타가 비어있음. brief 로직의 KB→technique 매핑 확인 필요.
