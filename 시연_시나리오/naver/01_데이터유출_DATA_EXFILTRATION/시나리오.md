# 시연 시나리오 — NCP 데이터 유출 (DATA_EXFILTRATION)

> **CSP**: 네이버 클라우드 (NCP) · **사고유형**: DATA_EXFILTRATION · **심각도**: critical
> **공격자 IP**: 115.91.214.5 (비국내) · **피해 계정**: attack-sim (탈취된 서브계정)

## 1. 사고 개요 (수사관 관점)

CRM 운영팀으로부터 "새벽 시간대에 고객 DB 버킷에서 대용량 내보내기 작업이
연속 발생했다"는 1차 신고가 접수되었다. 수사관은 NCP Cloud Activity Tracer 로그
일부를 우선 확보해 **AI Sherpa** 에 업로드하고 사고유형 추종을 시작한다.

## 2. 1단계 — 사고유형 선정용 로그 업로드

- **파일**: `01_사고유형선정_ncp_data_exfiltration.json`
- **내용**: 정상 로그인(alice/bob) → 공격자 로그인(attack-sim) → Object Storage
  **Request/Complete For Exporting** 반복 → **Disable AccessKey** 흔적 제거
- **시스템 판정**: `Request/Complete For Exporting To Object Storage` 의 반복 패턴이
  ATT&CK **T1567(Exfiltration Over Web Service) / T1537(Transfer to Cloud Account)** 로
  매핑되어 사고유형 후보 **DATA_EXFILTRATION** 이 최상위로 제시됨.
- 수사관은 후보를 확인하고 **DATA_EXFILTRATION 으로 확정**한다.
