# 시연 시나리오 — NCP 권한 상승 (PRIVILEGE_ESCALATION)

> **CSP**: 네이버 클라우드 (NCP) · **사고유형**: PRIVILEGE_ESCALATION · **심각도**: high
> **공격자 IP**: 115.91.214.5 (비국내) · **피해 계정**: attack-sim (탈취된 서브계정)

---

## 1. 사고 개요 (수사관 관점)

보안팀이 "새벽에 신규 서브계정 2개가 만들어지고 관리자 정책이 연달아 부여됐다"는
IAM 변경 알림을 받았다. 정상 변경 요청 티켓이 없어 침해를 의심, 수사관은 Activity
Tracer 로그를 확보해 **AI Sherpa** 에 업로드한다.

## 2. 1단계 — 사고유형 선정용 로그 업로드

- **파일**: `01_사고유형선정_ncp_privilege_escalation.json`
- **내용**: 공격자 로그인 → **Create sub account** → **Attach/Replace policy to sub account**
  → **Create Login Key / Create AccessKey**
- **시스템 판정**: 계정 생성·정책 부여·자격증명 발급 조합이 ATT&CK
  **T1136.003(Create Cloud Account) / T1098(Account Manipulation) /
  T1098.001(Additional Cloud Credentials)** 로 매핑 → 사고유형 후보
  **PRIVILEGE_ESCALATION** 최상위 제시.
- 수사관은 **PRIVILEGE_ESCALATION 으로 확정**한다.
