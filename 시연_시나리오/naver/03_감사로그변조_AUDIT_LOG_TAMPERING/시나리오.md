# 시연 시나리오 — NCP 감사로그 변조 (AUDIT_LOG_TAMPERING)

> **CSP**: 네이버 클라우드 (NCP) · **사고유형**: AUDIT_LOG_TAMPERING · **심각도**: critical
> **공격자 IP**: 192.0.2.55 (외부, curl) · **피해 계정**: finance-admin

---

## 1. 사고 개요 (수사관 관점)

야간에 **Cloud Activity Tracer 가 갑자기 비활성화**되고 이후 로그가 끊긴 정황이
모니터링에서 포착됐다. 로그 자체가 조작된 정황이라 수사관은 끊기기 직전까지
남은 Activity Tracer 로그를 긴급 확보해 **AI Sherpa** 에 업로드한다.

## 2. 1단계 — 사고유형 선정용 로그 업로드

- **파일**: `01_사고유형선정_ncp_audit_log_tampering.json`
- **내용**: 비정상 로그인(finance-admin) → **Disable/Delete Activity Tracer** →
  AccessKey/정책/계정/서버/버킷 **연쇄 삭제**
- **시스템 판정**: `Disable Activity Tracer`·`Delete Activity Tracer` 가 ATT&CK
  **T1562.008(Disable Cloud Logs)**, 연쇄 삭제가 **T1070(Indicator Removal)** 로 매핑되어
  사고유형 후보 **AUDIT_LOG_TAMPERING** 최상위 제시.
- 수사관은 **AUDIT_LOG_TAMPERING 으로 확정**한다.

## 3. 2단계 — 초동수집 가이드 (시스템 자동 생성)

| CT-NCP-AUDIT-001 | ACG/NACL 규칙 변경 | **REQUIRED** | T1562.007 |

| CT-NCP-AUDIT-006 | LB/서버 설정 변경 | CORROBORATING | T1578 |

| CT-NCP-AUDIT-008 | ACG/NACL 현재 스냅샷 | CORROBORATING | T1562.007 |

## 4. 3단계 — 가이드에 따른 증거 수집 (수사관 직접 수행)

- **파일**: `02_수집가이드_collected.json`
- Activity Tracer 가 꺼지기 **전** 구간(22:00~22:03)에 남은 핵심 이벤트와,
  변조 전후 비교용 설정 변경 이력을 수집.

| 수집 항목 | 확보한 증거 | 비고 |
|-----------|------------|------|
| CT-NCP-AUDIT-001 | 22:01 ACG `acg-prod-web` 0.0.0.0/0 인바운드 허용 | 방화벽 무단 개방 |
| CT-NCP-AUDIT-004 | 22:01 IAM `stage-user-temp` 에 Administrator attach | 권한 무단 변경 |
| CT-NCP-AUDIT-002 | 22:02 `temp-staging` 버킷 public-read 전환 | 공개 노출 |
| CT-NCP-AUDIT-003 | 22:03 `temp-staging` GetObject 1,280건 / 5GB | 대량 반출 |
| CT-NCP-AUDIT-006 | 22:04 서버 인스턴스 스펙 변경 | 인프라 변조 |
| (핵심) | 22:03 Disable / 22:15 Delete Activity Tracer | **로그 변조 본행위** |

> **로그 공백 명시**: 22:15 Tracer 삭제 이후 구간은 증거가 존재하지 않음 →
> GapDetector 가 **INTERPRETATION GAP(로그 공백)** 으로 표시.

## 5. 공격 체인 타임라인

```
22:00  로그인 (finance-admin, 192.0.2.55, curl)   ── Initial Access
22:01  ACG 0.0.0.0/0 개방 + IAM Admin 부여         ── Defense Evasion / Priv Esc
22:02  temp-staging 버킷 공개                        ── Collection      T1530
22:03  GetObject 1,280건(5GB) + Disable Tracer      ── Exfil + 로그변조  T1562.008
22:04  서버 스펙 변경 / AccessKey 삭제               ── 흔적 제거       T1070
22:15  Delete Activity Tracer  ▓▓ 이후 로그 공백 ▓▓  ── Anti-Forensics  T1562.008
```

## 6. 수사 결론

- **확정 사고유형**: AUDIT_LOG_TAMPERING (감사로그 비활성화·삭제로 추적 방해)
- **수집 완료율**: Tracer 종료 전까지의 REQUIRED 항목은 확보, 종료 후 구간은 공백
- **갭(GapDetector)**: **INTERPRETATION GAP** — 22:15 이후 행위는 로그 부재로 미상.
  복구 수단: VPC Flow Log·Object Storage 액세스 로그(별도 버킷) 교차 확보 권고
- **후속 권고**: Activity Tracer **외부 Object Storage 내보내기 + 변조 감지 알림** 상시화,
  192.0.2.55 차단, finance-admin 자격증명 회수
