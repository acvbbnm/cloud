# 시연 시나리오 — NHN 자격증명 탈취 (CREDENTIAL_THEFT)

> **CSP**: NHN Cloud · **사고유형**: CREDENTIAL_THEFT · **심각도**: critical
> **공격자 IP**: 94.156.169.42 (불가리아) · **피해 계정**: admin@startup.kr

---

## 1. 사고 개요 (수사관 관점)

정상 관리자(admin)가 "콘솔 로그인이 안 된다"고 신고했다. 동시에 해외 IP에서의
관리자 로그인 알림이 떠 있었다. 계정 탈취가 의심되어 수사관은 NHN Governance &
Audit → CloudTrail 로그를 확보해 **AI Sherpa** 에 업로드한다.

## 2. 1단계 — 사고유형 선정용 로그 업로드

- **파일**: `01_사고유형선정_nhn_credential_theft_real.json`
- **내용**: 로그인 실패 → **MFA 비활성화** → 로그인 성공(해외 IP) → 멤버 정찰 →
  **비밀번호 변경** → **S3 자격증명/keypair 생성**
- **시스템 판정**: MFA 무력화·비밀번호 변경·자격증명 생성 조합이 ATT&CK
  **T1556(Modify Authentication Process) / T1078.004(Valid Cloud Accounts) /
  T1098.001(Additional Cloud Credentials)** 로 매핑 → 사고유형 후보
  **CREDENTIAL_THEFT** 최상위 제시.
- 수사관은 **CREDENTIAL_THEFT 으로 확정**한다.
