## 1. 사고 개요 (수사관 관점)

운영 서비스가 새벽에 전면 중단되고, Object Storage 의 파일이 `.locked` 확장자로
바뀐 채 **랜섬 노트**가 발견됐다. 백업 스냅샷도 사라진 정황이라 수사관은
CloudTrail 의 Object/Instance/VPC 이벤트를 확보해 **AI Sherpa** 에 업로드한다.

## 2. 1단계 — 사고유형 선정용 로그 업로드

- **파일**: `01_사고유형선정_nhn_ransomware.json`
- **내용**: 로그인 → 데이터 다운로드(사전 유출) → **`.locked` 업로드/삭제** →
  백업 삭제 → **인스턴스 정지 / VPC 삭제**
- **시스템 판정**: 대량 객체 덮어쓰기·삭제 + 인스턴스 정지 + 인프라 삭제 조합이
  ATT&CK **T1486(Data Encrypted for Impact) / T1489(Service Stop) /
  T1490(Inhibit System Recovery)** 로 매핑 → 사고유형 후보 **RANSOMWARE** 최상위 제시.
- 수사관은 **RANSOMWARE 로 확정**한다.
